# مصمم كروت العطور | عطور إبراهيم الهاشمي

تطبيق ويب تقدمي (PWA) فاخر لتصميم وتخصيص كروت العطور وتصديرها بصيغة PNG فائقة الدقة للطباعة والمشاركة.

---

## 🚀 خطوات الرفع والنشر على GitHub Pages

### الطريقة الأولى: عبر أوامر Git في سطر الأوامر (Terminal)

افتح موجه الأوامر (PowerShell أو Git Bash) داخل هذا المجلد ونفّذ الأوامر التالية بالترتيب:

```bash
# 1. تهيئة المستودع
git init

# 2. إضافة كافة الملفات
git add .

# 3. حفظ التغييرات (Commit)
git commit -m "الإصدار الأول - مصمم كروت عطور إبراهيم الهاشمي"

# 4. تسمية الفرع الأساسي main
git branch -M main

# 5. ربط المستودع بمستودع GitHub
git remote add origin https://github.com/ibrahimhassona/perfume_cards_designer.git

# 6. الرفع إلى جيت هب
git push -u origin main
```

---

### تفعيل GitHub Pages من إعدادات المستودع

1. اذهب إلى صفحة المستودع على **GitHub**.
2. اضغط على تبويب **Settings** (الإعدادات).
3. من القائمة الجانبية اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - في خانة **Source** اختر: **GitHub Actions** (سيتم النشر تلقائياً بفضل ملف سير العمل المرفق `.github/workflows/deploy.yml`).
   - أو اختر **Deploy from a branch** وحدد الفرع `main` والمجلد `/(root)` واضغط **Save**.
5. خلال ثوانٍ سيظهر لك الرابط الحي لموقعك جاهزاً للاستخدام والمشاركة! 🌐

---

## 📱 التثبيت كتطبيق هاتف (PWA)

بمجرد فتح الرابط على الهاتف عبر متصفح **Chrome** أو **Safari**:
- **Android**: اضغط على القائمة (⋮) ثم **"تثبيت التطبيق"** أو **"إضافة إلى الشاشة الرئيسية"**.
- **iPhone / iOS**: اضغط على زر المشاركة ثم **"إضافة إلى الشاشة الرئيسية"** (Add to Home Screen).
- سيعمل التطبيق بكامل طاقته حتى دون اتصال بالإنترنت بعد الزيارة الأولى.

---

## 📁 هيكل الملفات

* `index.html`: واجهة المصمم، المحرك التفاعلي وتوليد الكروت.
* `.nojekyll`: يمنع نظام Jekyll من تجاهل الملفات ويبقي المسارات سليمة.
* `manifest.webmanifest`: تعريف التطبيق للأجهزة المحمولة.
* `sw.js`: Service Worker للتخزين المؤقت والعمل دون اتصال بالإنترنت.
* `logo.avif`: الشعار الرسمي لعطور إبراهيم الهاشمي.
* `.github/workflows/deploy.yml`: النشر الآلي لصفحات جيت هب.
